## 간단한 설명 (80자)

전국 명소 466곳, 도착해서 꾹 누르면 도장이 찍혀요. 다녀온 곳을 지도와 뱃지로 모아 보세요.

## 자세한 설명 (4000자)

여행 다녀온 곳, 기억으로만 남기기 아쉬우셨죠?
랜드마크는 전국 명소를 도장 찍듯 모으는 여행 기록 앱입니다.

■ 도착하면 꾹, 도장 한 번
명소 근처에 도착해 화면을 꾹 누르면 인주가 번지며 도장이 찍힙니다. 복잡한 가입이나 입력 없이, 누르기만 하면 됩니다.

■ 다녀온 곳에 사진 한 장
도장을 찍은 명소에는 사진을 남길 수 있습니다. 사진 위에 그날의 도장과 날짜가 함께 찍힙니다.

■ 전국 명소 466곳
한국관광 100선, 100대 명산, 국립공원, 궁궐과 사찰, 시장과 이름난 가게까지. 내 주변 · 근교 · 시도 · 전국으로 지도를 넓혀 가며 볼 수 있습니다.

■ 모을수록 쌓이는 뱃지
지역을 다 모으면 지역 뱃지, 주제별로 모으면 주제 뱃지. 다음 여행지를 고르는 재미가 생깁니다.

■ 여행과 가이드
다녀온 곳을 여행으로 묶어 카드로 간직하고, 나만의 코스를 가이드로 만들어 나눌 수 있습니다.

■ 길찾기는 쓰던 지도 앱으로
명소 화면에서 바로 네이버 지도, 카카오맵, 구글 지도로 길찾기를 열 수 있습니다.

■ 어르신도 쓰기 쉽게
글자는 크게, 버튼은 넓게, 말은 쉽게 만들었습니다.

■ 기록은 안전하게
로그인하지 않아도 폰에 기록이 남습니다. 구글·카카오·네이버로 로그인하면 서버에 보관되어 폰을 바꿔도 이어 쓸 수 있습니다. 광고가 없고, 백그라운드에서 위치를 쓰지 않습니다.

## 데이터 보안 양식 답변

| 질문 | 답 |
|---|---|
| 사용자 데이터를 수집하거나 공유하나요? | 수집함, 공유 안 함 |
| 전송 중 암호화 | 예 |
| 삭제 요청 방법 제공 | 예 (앱 안 탈퇴 + 삭제 안내 페이지) |

| 데이터 종류 | 수집 | 필수 여부 | 목적 |
|---|---|---|---|
| 이메일 주소 | 구글·카카오·네이버 로그인 시 | 선택 | 계정 관리 |
| 이름(닉네임) | 정할 때 | 선택 | 앱 기능 |
| 사용자 ID | 로그인 시 | 선택 | 계정 관리 |
| 사진 | 명소에 올릴 때 | 선택 | 앱 기능 (공개됨) |
| 정확한 위치 | 수집 안 함 (폰 안에서만 사용, 서버로 보내지 않음) | - | - |
| 앱 상호작용(하루 한 번 이용 날짜) | 자동 | 필수 | 분석 |
| 기기 ID | 임의로 만든 번호만 | 필수 | 분석 |

주의: 명소 제안·수정 제안에서 사용자가 직접 고른 좌표는 서버로 갑니다. 사용자의 현재 위치가 아니라 고른 지점이므로 "위치 수집"에 해당하지 않는다고 보지만, 심사에서 물으면 이렇게 설명합니다.

## 권한 설명 (심사에서 묻는 것)

| 권한 | 쓰는 이유 |
|---|---|
| 위치 (앱 사용 중) | 명소 인증 반경 안에 있는지 확인, 지도에 내 위치 표시 |
| 알림 | 저녁에 오늘 다녀온 곳 정리 알림 (허용한 경우만) |

사진첩 전체 접근 권한(READ_MEDIA_IMAGES)은 쓰지 않습니다. 사진은 시스템 사진 선택 창과 카메라로만 받습니다.

## 콘텐츠 등급 설문

- 폭력·성적 내용·도박·약물: 없음
- 사용자 제작 콘텐츠: 있음 (사진, 가이드) — 신고·차단·24시간 내 검토 있음
- 위치 공유: 없음
- 예상 등급: 전체이용가 (사용자 간 상호작용 표시)
